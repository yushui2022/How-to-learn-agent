# 示例代码

这里放每章配套的小型示例代码。

## 示例代码原则

- 一个示例只服务一个教学目标。
- 示例要尽量短小、可运行、可修改。
- 示例目录要标注对应章节。
- 示例不要提前引入后续章节的复杂能力。
