# 综合项目占位

这里放综合实战项目。项目不是零散 demo，而是把主线章节中的能力串起来。

完整项目主线见 [PROJECT_TRACKS.md](../PROJECT_TRACKS.md)。

## 项目应该怎么写

每个项目建议包含：

- 场景说明
- 需求拆解
- 架构图
- 最小版本
- 加入 RAG
- 加入工具调用
- Agent 化改造
- 评估方法
- 安全和生产化注意点

## 候选项目

- 知识库学习助手
- 个人研究 Agent
- 客服工单 Agent
- 数据分析 Agent
- 代码仓库助手
- 多 Agent 内容生产流程

## 和主线章节的关系

综合项目应该在第 18 章之后阅读，也可以作为每个部分结束后的阶段性练习。项目作者需要标注项目用到了哪些章节知识。
