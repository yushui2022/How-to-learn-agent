# Lab 03：个人助手与数字分身

> 状态：planned

## Lab 定位

本 Lab 关注个人 Agent 如何处理长期会话、用户偏好、跨渠道入口、任务记录、隐私和个性化。

## 对应章节

- 第 10 章：Agent 到底是什么
- 第 13 章：Memory 与 State
- 第 16-18 章：观测、安全和生产化

## 推荐项目

- 主案例：[OpenClaw](https://github.com/openclaw/openclaw)
- 主案例：[Letta](https://github.com/letta-ai/letta)
- 辅助案例：[OpenHuman](https://github.com/openhuman-ai/openhuman)

## 承接主线

读者理解 Agent、Memory 和 State 后，再讨论个人助手为什么需要记住偏好、维护身份边界、区分临时上下文和长期记忆。

## 学习任务

- 任务 1：拆分个人助手中的三类数据：当前任务上下文、长期记忆、系统配置。
- 任务 2：选择一个记忆写入场景，说明什么时候应该写入，什么时候应该忽略。
- 任务 3：设计用户可查看、可删除、可关闭的记忆控制方式。

## 项目迁移

把能力迁移到“AI 学习助手”：让它记住学习目标、已学章节和薄弱点，但不要默认记录敏感信息。

## 产出标准

- 一张个人助手数据分层图。
- 一份记忆写入规则。
- 一份隐私和用户控制清单。

## 写作边界

不要把个人助手写成“什么都能做”的幻想产品。重点是数据边界、记忆策略和用户控制。
