# Lab 07：低代码与无代码 Agent 平台

> 状态：planned

## Lab 定位

本 Lab 关注低代码平台如何把模型、Prompt、RAG、工具、工作流和发布能力可视化。

## 对应章节

- 第 06 章：AI 工作流
- 第 07-08 章：RAG 基础与评估
- 第 18 章：Production 上线、成本与迭代

## 推荐项目

- 主案例：[Dify](https://github.com/langgenius/dify)
- 主案例：[Flowise](https://github.com/FlowiseAI/Flowise)

## 承接主线

读者先理解工作流、RAG 和工具调用，再看低代码平台。这样读者不会只会拖节点，而能理解每个节点背后的工程含义。

## 学习任务

- 任务 1：把一个低代码流程还原成普通代码里的步骤。
- 任务 2：比较低代码平台和手写代码在可控性、可调试性、部署和协作上的差异。
- 任务 3：设计一个适合非工程人员使用的“AI 学习助手”工作流。

## 项目迁移

把能力迁移到“客服工单 Agent”：用低代码平台快速验证流程，再决定哪些部分需要手写代码沉淀。

## 产出标准

- 一张低代码流程图。
- 一份平台和代码实现对比表。
- 一个可演示的原型任务说明。

## 写作边界

不要把低代码平台写成初学者唯一选择。它适合验证流程和协作，但复杂项目仍然需要理解底层结构。
