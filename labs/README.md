# 源码 Lab 总览

源码 Lab 是本课程的第三条学习线。它不替代主线章节，也不替代综合项目，而是嵌入每章的“成熟项目讲解”，把真实开源项目拆成可学习的小任务。

## 使用方式

建议读者先按 `lessons/` 学主线概念，再在每章的“成熟项目讲解”中进入对应 Lab。每个 Lab 都应该回答：

- 这个项目解决什么真实问题。
- 它对应主线课程中的哪个概念。
- 本次只读哪一小块源码或文档。
- 读完后如何回到本章任务，并反哺“AI 学习助手”或可选项目。

## Lab 写作模板

每个 Lab 至少包含：

```text
Lab 定位
对应章节
推荐项目
承接主线
学习任务
项目迁移
产出标准
写作边界
```

源码 Lab 的重点是服务章节教学：本章讲什么概念，就拆成熟项目中最相关的一个源码切口。它不是堆项目名、Star 数或营销式评价。
