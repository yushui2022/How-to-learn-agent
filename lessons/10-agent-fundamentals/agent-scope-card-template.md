## 决策策略

写清楚 Agent 如何选择下一步。

```text
如果用户还没有学完基础章节，先安排基础复习。
如果用户练习错误集中在同一知识点，优先生成专项练习。
如果工具返回没有资料，停止并说明资料不足。
如果连续两次行动没有进展，请求用户确认或人工接管。
```

## 日志字段

| 字段 | 说明 |
| --- | --- |
| step_id | 当前第几步 |
| observation | 看到的输入、工具结果或用户反馈 |
| decision | 为什么选择下一步 |
| action | 调用了什么工具或生成了什么输出 |
| result | 动作结果 |
| stop_reason | 为什么停止 |
