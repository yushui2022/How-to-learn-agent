## AI 学习助手参考样例

| 编号 | 用户输入 | 期望行为 | 不应该出现什么 |
| --- | --- | --- | --- |
| 1 | 什么是 RAG？ | 解释清楚“检索后再回答”，指出不是让模型背知识，给一个小练习 | 只给术语定义 |
| 2 | Agent 和工作流有什么区别？ | 说清关键差别是下一步是否动态决策 | 把所有 LLM 应用都叫 Agent |
| 3 | ReAct 是什么？ | 解释观察、思考、行动交替，并给练习 | 只展开英文缩写 |
| 4 | 我总是把 Prompt 写很长怎么办？ | 指出可能是任务、约束、示例混在一起 | 只说“写清楚一点” |
| 5 | 帮我学会所有 AI | 先澄清基础、方向和时间 | 直接生成庞大学习计划 |
