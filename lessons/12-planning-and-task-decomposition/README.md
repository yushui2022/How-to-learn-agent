# 第 12 章：Planning 任务拆解与计划执行

> 状态：planned

## 本章定位

教读者处理更长任务：先拆解任务，再按计划执行，并在必要时调整计划。

## 承接上一章

上一章讲了 Agent 的单步循环。本章把单步循环扩展成多步骤任务执行。

## 铺垫下一章

下一章会讲 Memory 与 State。本章会产生任务计划、执行进度和中间结果，这些都需要状态管理。

## 本章要写什么

- Planning 的价值和风险。
- 任务拆解方法。
- Planner 和 Executor 的关系。
- 计划执行、检查和重新规划。
- 如何避免计划过度复杂。

## 本章不要写什么

- 不要把 Planning 写成项目管理课。
- 不要提前展开长期记忆。
- 不要默认每个任务都需要复杂计划。

## 建议示例

让 Agent 把“调研一个主题并产出摘要”拆成搜索、阅读、整理和输出几个步骤。
