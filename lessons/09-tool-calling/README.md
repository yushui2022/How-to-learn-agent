# 第 9 章：Tool Calling 工具调用

> 状态：planned

## 本章定位

教读者让模型从生成文本走向调用外部能力，例如查询数据、调用 API 或执行受限操作。

## 承接上一章

前两章讲了让模型使用外部知识。本章扩展到让模型使用外部工具。

## 铺垫下一章

下一章会正式定义 Agent。本章需要先让读者理解“行动”是如何通过工具调用发生的。

## 本章要写什么

- Tool Calling 的基本概念。
- 工具 Schema 如何设计。
- 参数校验和错误处理。
- 工具调用的权限边界。
- 如何记录工具调用日志。

## 本章不要写什么

- 不要直接进入复杂 Agent 框架。
- 不要让工具执行高风险操作。
- 不要忽略失败和重试。

## 建议示例

给模型两个工具：查询本地资料和执行简单计算，让模型根据用户问题选择是否调用工具。

## 建议图解

画一张工具调用时序图：模型请求工具、应用执行工具、结果返回模型、模型生成最终回答。
