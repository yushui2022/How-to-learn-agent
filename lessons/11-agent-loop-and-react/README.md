# 第 11 章：Agent 执行循环与 ReAct

> 状态：planned

## 本章定位

讲清楚 Agent 如何在目标、思考、行动、观察和反馈之间循环执行。

## 承接上一章

上一章定义了 Agent 的边界。本章开始解释 Agent 内部最小执行机制。

## 铺垫下一章

下一章会讲任务拆解和计划执行。本章需要先让读者理解单步行动和观察反馈。

## 本章要写什么

- Agent 执行循环。
- ReAct 的基本思想。
- 行动结果如何影响下一步。
- 何时停止执行。
- 循环失控和重复调用的风险。

## 本章不要写什么

- 不要深入长期计划。
- 不要提前讲多 Agent。
- 不要让示例无限循环。

## 建议示例

实现一个最多执行 3 步的简单 Agent，让它根据观察结果决定下一步。

## 建议图解

画一张 Agent loop：目标、推理、工具调用、观察、继续或停止。
