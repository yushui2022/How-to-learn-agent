# 第 8 章：RAG 进阶与评估

> 状态：planned

## 本章定位

帮助读者理解 RAG 跑通之后为什么还会答不好，以及如何定位问题。

## 承接上一章

上一章跑通了最小 RAG。本章继续解决检索不准、上下文不合适、回答不可靠等问题。

## 铺垫下一章

下一章会讲工具调用。本章让读者先学会评估外部信息是否被模型正确使用，为后续评估 Agent 行动打基础。

## 本章要写什么

- RAG 常见失败原因。
- Chunk 大小、召回数量和重排的影响。
- 检索评估和回答评估的区别。
- 如何构建小型测试集。
- 如何记录检索片段和最终回答。

## 本章不要写什么

- 不要展开 Agent 评估。
- 不要把所有检索算法都讲一遍。
- 不要只讨论工具选型。

## 建议示例

准备 10 个问题，检查每个问题是否检索到了正确资料，以及回答是否引用了正确依据。

## 建议图解

画一张 RAG 调试流程图：问题、检索结果、上下文、回答、评估。
