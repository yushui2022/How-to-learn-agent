# 第 7 章：RAG 基础

> 状态：planned

## 本章定位

教读者理解 RAG 的基本流程：不是让模型记住知识，而是在回答前把相关资料找出来。

## 承接上一章

上一章讲了工作流。本章把“检索资料”作为工作流中的关键步骤加入进来。

## 铺垫下一章

下一章会讲 RAG 的优化和评估。本章需要先让读者跑通最小 RAG 流程。

## 本章要写什么

- RAG 解决什么问题。
- 文档加载、清洗和切分。
- Embedding 和向量检索的直观解释。
- 检索结果如何放进 Prompt。
- 引用来源的重要性。

## 本章不要写什么

- 不要深入复杂重排和评测指标。
- 不要引入太多向量数据库选型。
- 不要把 RAG 和 Agent 混在一起讲。

## 建议示例

读取几篇 Markdown 文档，检索相关片段，再让模型基于片段回答问题。

## 建议图解

画一张 RAG 流程图：文档、切分、索引、检索、生成、引用。
