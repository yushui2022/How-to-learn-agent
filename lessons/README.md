# 主线章节说明

这里放正式课程主线。每个章节一个文件夹，每个文件夹至少包含一个 `README.md`。

## 章节文件夹规则

章节目录使用两位数字开头：

```text
00-course-setup/
01-ai-project-map/
02-from-idea-to-prototype/
```

这样做是为了保证目录顺序稳定，也方便 Issue、PR 和示例代码对应章节。

## 每章 README 现在应该包含什么

当前阶段，每章 README 不是正式正文，而是写作占位。它需要说明：

- 本章定位。
- 和上一章的承接关系。
- 为下一章铺垫什么。
- 这里应该写什么。
- 这里不应该写什么。
- 建议示例。
- 建议图解。

## 后续扩展建议

当某章进入正式写作阶段，可以逐步增加：

```text
README.md       # 正式章节正文
examples/       # 本章小示例
images/         # 本章图解
notes.md        # 写作备忘和资料
```
